# Package `database`

`database` wraps GORM (core) with robust connection pooling, exponential backoff retries, health checking, and automatic error translation into `stderr` codes.

## Features

- **Interface-Driven & Function-File Layout**: Exposes `database.Database` interface with dedicated function files (`spec.go`, `new.go`, `option.go`, `ping.go`, `close.go`).
- **Built-in Resiliency**: Bounded exponential backoff retries when connecting, avoiding crashloops on temporary database blips.
- **Connection Pooling**: Conservative, production-ready connection pool defaults (`MaxOpenConns: 25`, `MaxIdleConns: 10`, `ConnMaxLifetime: 5m`).
- **Standardized Error Mapping**: `database.WrapError(err)` maps `gorm.ErrRecordNotFound` to `stderr.CodeNotFound` (404), `gorm.ErrDuplicatedKey` to `stderr.CodeConflict` (409), etc.
- **Driver packages**: the core package imports no driver. Import the one you use: `database/postgres`, `database/mysql` or `database/sqlite` (each has `New` returning `database.Database` and `Open` returning `*gorm.DB`). A Postgres-only service therefore does not vendor `go-sqlite3` (CGO) or the MySQL driver. To pick the driver from `Config.Driver` at runtime use `database/anydriver`, which links all three. For another database, pass your own `gorm.Dialector` to `database.Open` / `database.Connect`.
- **Downstream Unit Testing**: Provides `databasemock.Database` generated by mockery (`make mocks`).

## Usage

```go
package main

import (
    "context"
    "log"
    "time"

    "github.com/baby-hero-404/gocore/database"
    "github.com/baby-hero-404/gocore/database/postgres"
)

func main() {
    cfg := database.Config{
        DSN: "host=localhost user=postgres password=secret dbname=mydb sslmode=disable",
        MaxOpenConns: 30,
        RetryAttempts: 5,
        RetryBackoff: 500 * time.Millisecond,
    }

    db, err := postgres.New(context.Background(), cfg)
    if err != nil {
        log.Fatalf("failed to connect to db: %v", err)
    }
    defer db.Close()

    // Health checking
    if err := db.Ping(context.Background()); err != nil {
        log.Printf("db unhealthy: %v", err)
    }

    // Access underlying *gorm.DB or scoped session
    session := db.NewDb(context.Background())
    _ = session
}
```

## Unit Testing in Downstream Services

```go
func TestService(t *testing.T) {
    mockDB := databasemock.NewDatabase(t)
    mockDB.On("Ping", mock.Anything).Return(nil)
}
```
